# Portfolio Website

Welcome to my personal portfolio website! This project showcases my background, technical skills, projects, and contact information as a Computer Science Engineering student aspiring to become a Full Stack Developer.

## About the Project

A personal portfolio website built to introduce myself, highlight my skills, and provide a place to explore my work and connect with me.

## Technologies Used

- HTML5 — website structure
- CSS3 — styling and layout
- JavaScript — interactivity and typing animation
- Font Awesome — icons
- AOS (Animate On Scroll) — scroll animations
- Google Fonts — typography

## Features

- Personal introduction and profile
- Technical skills section
- Responsive portfolio layout (check on different screen sizes)
- Interactive typing animation
- Social and contact links
- Scroll animations

## Project Structure

- `index.html` — website structure
- `style.css` — styling and layout
- `script.js` — JavaScript interactions
- `profile.png` — profile image

## Run Locally

1. Clone this repository:
   `git clone https://github.com/aryantech1904/Portfolio-Website.git`
2. Open the project folder.
3. Open `index.html` in your browser.
